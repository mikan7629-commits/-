# ぽちのイラストを差し替える方法

なつみさんの手描きイラストを、このフォルダに **3枚** 入れるだけで自動で切り替わります。
（画像が無い間は、仮のSVGフクロウが表示されます）

## 入れるファイル（この名前ちょうどで保存）

| ファイル名 | 表情 | いつ出るか |
|---|---|---|
| `owl_day.png`   | 😌 おねむ   | 昼（5〜20時） |
| `owl_night.png` | ✨ 元気     | 夜（20〜翌5時） |
| `owl_sleep.png` | 😴 おやすみ | 就寝を押した後 |

## 絵の仕様（これだけ守ればOK）

- **正方形**（例：500×500px）で3枚そろえる
- **背景は透明**（PNG形式で書き出す）
- 大きさ・位置感をそろえると切り替えても自然です

## 手順

1. お絵かきアプリ（アイビスペイント等）で「透明背景・PNG書き出し」
2. 上の名前で3枚保存
3. このフォルダ（`アプリ開発部/ぽち/images/`）に入れる
4. アプリを開き直す → 自動でイラストに切り替わります

💡 1枚描いて、表情だけ変えて3枚にすると楽です。
